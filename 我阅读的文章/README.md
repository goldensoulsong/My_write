# 我阅读的文章

放外部文章的中文译述版本，以便在我的写作里引用、回看、做对照。

## 原则

- **不是替代原文**。译文做了精炼和改写，引用论点时回到原文核对。
- **合规标注**。译文里都标了 `Content was rephrased for compliance with licensing restrictions`，避免连续逐字翻译超过 30 词。
- **保留原文链接**。每篇开头都有原文 URL，方便随时跳回。

## 命名规则

`YYYY-MM-DD-标题.md`，日期是**原文发布日期**（不是我读到的日期），方便按时间排序。
