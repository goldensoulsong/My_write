# Harness：广泛学习各大开源项目记录

> **模型是驾驶者，Harness 是载具。** 缺了模型，载具是个空壳；缺了 Harness，模型无处施展。两者合在一起，才是一个完整的、能解决实际问题的 Agent。

## 这个系列是什么？

这是我以一个 Harness 工程师的视角，逐行拆解顶级开源 Agent 代码仓库的学习记录。

不是转述别人的总结，不是复读论文的摘要，而是我自己一行一行读完代码之后的理解和思考。

## 核心认知

- **Agency 来自模型训练**，不是来自外部代码的编排。
- **AI 本质是求解器**，我们要做的是定义解空间，在解空间内让 AI 进行收敛。
- **Harness 工程师**的工作核心：实现工具、策划知识、管理上下文、控制权限、收集任务过程数据。

## 为什么从 Claude Code 开始？

因为 Claude Code 是我们所见过的最优雅、最完整的 Agent Harness 实现，本质上是一种 Runtime。它展示了当你信任模型、把工程精力集中在 Harness 上时会发生什么。
